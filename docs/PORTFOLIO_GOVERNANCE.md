# Portfolio Governance Baseline

TradingView integration is infrastructure for market data and analysis, not a guarantee of trading outcomes.

- Respect platform terms, API limits and data licensing.
- Do not expose credentials in client code or commits.
- Label live, delayed, simulated and historical data accurately.
- Reproducible tests must separate strategy logic from data-provider behaviour.
- No claims of guaranteed profit, accuracy or passive income.
- Log important automated actions and provide kill switches where automation can place or modify orders.
- Financially consequential outputs require appropriate review and risk disclosure.
